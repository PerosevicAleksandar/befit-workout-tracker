# BeFit Frontend Foundation

## Build
- Replace the starter screen with a responsive BeFit application shell and shared navigation.
- Add routes for Home, Login, Register, Add Workout, My Workouts, and dynamic Workout Details.
- Use mock workout records throughout, with newest-first history and linked detail pages.
- Add the requested forms, dashboard metrics, action buttons, responsive table, and future empty state.

## Design
- Create a clean athletic visual system with crisp typography, compact rounded corners, blue light-mode accents, and red dark-mode accents.
- Use a desktop navigation bar and accessible mobile menu.
- Add a working theme control saved locally across refreshes.

## Validation
- Verify all navigation, the mobile menu, both themes, forms, and dynamic workout links in the running preview.
- Check desktop and mobile layouts and ensure every page has unique sharing and search metadata.

## Technical details
- Keep the existing TanStack Start/Vite foundation and use its file-based React routes instead of adding another router.
- Keep all data and interactions frontend-only; no Cloud, authentication, database, save, or delete implementation.
